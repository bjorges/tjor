# ADR 0001 — Name, license, repo home

**Date:** 2026-09-04 · **Status:** accepted

- **Name: `tjor`** (nynorsk: tether). One word for the security model: the agent grazes freely within a bounded radius. Verified free as a GitHub repo name and Homebrew formula name at decision time.
- **License: MIT** — matches the ecosystem tjor composes with (cplt, LiteLLM, OpenSpec are all MIT).
- **Home:** `github.com/bjorges/tjor`, public. Developed as a personal weekend project on personal time and personal infrastructure; commits use the author's personal GitHub identity.
- **Distribution goal:** a Homebrew tap (`brew install bjorges/tap/tjor`) once there is something to install; homebrew-core only if adoption ever warrants it.
